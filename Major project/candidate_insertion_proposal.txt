Learning to Insert: Image-Grounded Cell Recovery
from Incomplete Table Structure Predictions
Project Proposal
October 2026
Abstract
Table Structure Recognition (TSR) systems usually predict a set of table cells and then
convert these predictions into a final logical structure. A recurring failure is an omitted cell
instance: the image may contain a valid cell, but the detector does not provide a usable
candidate for it. A later selector can choose among existing candidates, but it cannot select a
candidate that is absent. This proposal studies whether a TSR model can explicitly expand
an incomplete candidate set by inserting new cell hypotheses from the table image and the
surviving detected cells.
The project is deliberately narrower than general table reconstruction. The proposed
task is detection-conditioned cell insertion : given a table image and an incomplete set of
cell candidates produced by a base detector, predict whether an additional cell should be
inserted and, when appropriate, estimate its box and logical span. The insertion decoder
must also support a no-insertion outcome and avoid subdividing a valid spanning cell. The
first implementation will attach a lightweight recovery decoder to a fixed cell detector, with
a set or graph encoder for surviving-cell context and image-attention queries for candidate
generation. Training will start with controlled deletion of correct candidates and will then
move to natural detector omissions. Evaluation will distinguish cells that were merely filtered
from cells absent even from a generous pre-filter candidate pool.
The literature review shows that missing-cell reconstruction, vacancy detection, topology-
aware refinement, and joint spatial-logical prediction have all been studied. The proposed
contribution is therefore not “missing-cell reconstruction” in general. The narrower question
is whether a learned, variable-cardinality insertion operator can expand an incomplete
detector-produced candidate set using raster evidence and surviving-cell context, while
explicitly learning when notto insert. The core evidence required is recovery of natural
omissions at matched insertion precision, with ablations showing that both image evidence
and surviving-cell context contribute.

1.2 Central research question
Can a learned insertion operator recover cell instances that are absent from an
incomplete detector candidate set, using surviving-cell context and raster-image
evidence, without introducing unsupported cells or breaking valid spans?
1.3 Research hypotheses
1.H1 - Candidate incompleteness: A non-trivial fraction of TSR cell errors can be traced
to cells that are missing from the retained candidate set.
2.H2 - Threshold relaxation is insufficient: Lowering the detector threshold can increase
candidate recall, but the resulting false positives and duplicates prevent it from being an
equivalent solution to learned insertion.
3.H3 - Learned insertion can recover natural omissions: A recovery decoder can
generate correct cell instances that are absent even from a generous pre-filter candidate pool.
4.H4 - Two sources of evidence matter: Surviving-cell context and local image evidence
each contribute to insertion accuracy; removing either should reduce performance.
5.H5 - Explicit no-insertion matters: A model trained to decide whether to insert, rather
than only to predict a box, should reduce false insertions and erroneous subdivision of
spanning cells.
2 Literature Survey
The project sits at the intersection of cell detection, structural relation modeling, table reconstruc-
tion, and recent image-to-structure models. The important distinction is between methods that
improve the original detector, methods that assemble a full structure from predicted elements,
and methods that explicitly create additional cell instances.

2.1 Early cell and structure detection
Early TSR systems approached table structure as either a detection problem or a decomposition
problem. DeepDeSRT used deep detection and structure recognition for document tables [ 1].
CascadeTabNet combined table detection and cell recognition in a CNN-based pipeline [ 2].
GraphTSR framed TSR as graph relation prediction between detected table cells and established
a graph-based formulation for complex scientific tables [ 3]. These methods demonstrate that cell
localization alone does not determine the final table structure; relations among cells are needed.
2.2 Split-and-merge and grid-based methods
Split-and-merge systems predict a regular representation and subsequently merge elements to
account for spanning cells. Deep Splitting and Merging [ 4] and SEM (Split, Embed and Merge)
[5] are representative examples. TSRFormer models table separators with a Transformer and
reconstructs spans from the predicted grid [ 9]. GridFormer uses grid prediction and structural
relations to model the table layout [10].
These methods are relevant because a regular grid can expose apparent vacancies. However, the
existence of a geometric vacancy is not enough to establish that an independent cell should be
inserted. A vacancy may be an empty region belonging to a spanning cell or may arise from an
imperfect detection.
2.3 Global structure and learned reconstruction
LGPMA (Local and Global Pyramid Mask Alignment) is particularly relevant to the proposed
problem [ 6]. It predicts local cell-related information together with global table segmentation and
includes an empty-cell recovery process based on structural alignment. Its recovery procedure
searches for vacant positions and uses image-level segmentation to determine how regions should
be merged.
LGPMA therefore rules out a broad novelty claim of “combining topology with image evidence
for missing-cell recovery.” The proposed work needs to address a different intervention: learned
insertion of omitted cell instances into an incomplete detector-produced candidate set, including
a learned decision not to insert.
Relation and logical-coordinate methods further emphasize structural reasoning. TGRNet jointly
predicts spatial and logical locations and reconstructs the table graph [ 7]. LORE uses an
anchor-free detection formulation and predicts logical coordinates alongside spatial boxes [ 13].
TableCenterNet similarly targets one-stage prediction of spatial and logical cell locations [ 15].
These methods strengthen the detector or predict structure jointly; they do not, by themselves,
establish an insertion operator whose output cardinality can exceed an incomplete candidate set.
2.4 Sequence generation and image-to-structure models
TableFormer uses Transformer decoding for table structure understanding and combines cell
localization with structured sequence generation [ 11]. VAST introduces visual-alignment sequen-
tial coordinate modeling and uses visual alignment to improve coordinate prediction [ 14]. More
recent models extend this trend. TableSeq represents image, structure, and cell localization in a
unified autoregressive sequence [ 23]. FastTab uses recursive structure prediction and ROI-aligned
features for grid and span inference [ 24]. StrucTab introduces intermediate structural supervision
and a structured optimization framework for table parsing [ 25]. BGTR uses detected bounding

--- PAGE 4 ---
boxes to guide HTML generation [ 26]. TPGCAT introduces text-prior-guided cell alignment for
table structure recognition [27].
These models show that strong TSR systems can reason over geometry and structure jointly.
They do not make the specific problem of expanding an incomplete candidate set the primary
inference operation.
2.5 Missing-cell and reconstruction methods
The closest direct prior work is a line of table reconstruction methods that infer cells absent
from an initial detection. The historical-record reconstruction work published in IJDAR in 2025
explicitly infers missing cells from the horizontal and vertical alignment of detected positive cells
and generates candidates at identified gaps [ 16]. A related 2025 IJDAR study on semi-supervised
TSR also evaluates missing-cell generation and reconstruction in historical tables [17].
These systems establish that coordinate-based candidate generation from surviving detections is
not new. They motivate using such geometric completion as a required baseline rather than as
the proposed method.
TableFormer also contains PDF-oriented handling of orphan content that can lead to structural
cell creation from document geometry [ 11]. This is not equivalent to the proposed raster-only
inference setting because PDF text and geometry provide information that is unavailable to a
pure image-based model. It is nevertheless evidence that structural cell creation itself is not a
new operation.
2.6 Detector failure and suppression
Detection-based TSR systems also expose a different route to omission: the detector can generate
a weak prediction that is later removed. Table Transformer (TATR) uses DETR-style object
detection for cells, rows, and columns in the PubTables-1M benchmark [ 12]. TableCenterNet,
LORE, and other detector families similarly rely on confidence scores or peak selection. Recent
work such as OG-HFYOLO focuses on improving table-cell instance detection and reducing
omissions or suppression errors [ 21]. ConRTF targets boundary localization through an edge-
constrained training objective rather than a candidate insertion stage [22].
These methods suggest an important experimental control: any learned recovery method must
be compared against simply lowering the detector threshold or improving the detector itself.
2.7 Scene and deformed tables
WTW (“Parsing Table Structures in the Wild”) was introduced for tables with natural visual
deformation, including inclined, curved, blurred or occluded, extreme-aspect-ratio, overlaid,
multicolor, and irregular tables [ 8]. Methods such as SCAN address inclined and curved tables
using segmentation collaboration and cell alignment [ 20]. WTW is therefore useful as a stress
test for whether candidate insertion remains valid when a regular-grid assumption becomes
unreliable.

The proposed contribution is therefore not a new form of geometric gap filling. It is a learned
operator that takes an incomplete set of detector-produced instances and decides whether
additional instances are justified by the image and the surviving table structure. The output
cardinality is allowed to grow, and the model can explicitly output “no insertion.”
A proposed formal statement is:
We study detection-conditioned cell insertion for TSR: given a raster table image
and an incomplete candidate set produced by a base cell detector, learn a variable-
cardinality decoder that inserts additional cell instances only when image evidence
and surviving-cell context support them, while preserving valid spanning structures.
This claim is deliberately weaker than a “first missing-cell recovery” claim. A final first-of-its-kind
statement should only be made after an exhaustive search immediately before submission.
4 Proposed Framework
4.1 Design principles
The first implementation should satisfy five constraints:
1. The base detector is kept fixed when measuring the contribution of recovery.
2.The recovery module operates on raster image features and detector outputs; OCR or PDF
metadata are not required at inference.
3.The recovery decoder has a variable number of outputs rather than one fixed query per
geometric gap.

--- PAGE 6 ---
4.A candidate may be classified as “no insertion,” which prevents the model from turning
every vacancy into a cell.
5.Existing detector predictions are initially left unchanged so that the experiment isolates the
value of candidate insertion.
4.2 Initial host detector
The first host should be Table Transformer (TATR) because it has an established implementation,
is trained for cell/row/column detection on PubTables-1M, and exposes explicit cell boxes
and confidence scores [ 12]. The same recovery module can later be attached to LORE or
TableCenterNet to test whether the method is tied to one detector family [13, 15].

For an inserted candidate cj, a compatibility head estimates whether the proposal is geometri-

if the simple version produces useful recovery gains.
5 Training Strategy
5.1 Controlled candidate deletion
The first training stage creates incomplete candidate sets from annotated tables. Let C+be the
subset of ground-truth cells represented by correctly matched base-detector candidates. A mask
M⊂C+is sampled and removed from the input candidate set:
C′
0=C0\M. (15)
The image remains unchanged. The recovery decoder is trained to produce candidates matching
the removed cells.
Deletion should not be purely random. Four cases should be included:
1. isolated cell deletion;
2. adjacent deletion of two or more cells;
3. deletion near a spanning cell;
4. deletion patterns sampled from real detector errors.
The last case is introduced after a baseline detector has been profiled.

5.3 Transition to natural omissions
After the synthetic deletion stage converges, the training data should include candidate sets
produced by the real detector. For each image, the recovery module sees exactly the candidates
that the detector would normally retain. Ground truth is used only to define targets during
training. At test time the module receives no deletion mask and no ground-truth topology.
6 Experimental Design
6.1 Evaluation protocol 1: controlled omissions
Start from detector outputs and deliberately remove selected true-positive candidates while
leaving the original image untouched. This isolates the insertion capability from the detector’s
unrelated errors.
Evaluate deletion rates of 10%, 20%, 30%, 40%, and 50% of eligible candidates. The evaluation
should contain isolated deletions, adjacent deletions, and deletions close to spanning cells. Intact
tables with no deleted candidates are also required. On those tables, the correct behavior is
often “no insertion.”
6.2 Evaluation protocol 2: natural omissions
Run the base detector normally. After inference, match its candidates to the ground-truth cells
only for analysis. Split the missed cells into two groups:
1.filtered omissions : a corresponding candidate exists in a pre-filter or low-confidence pool
but is removed by the standard threshold;
2.proposal omissions : no candidate in a generous pre-filter pool matches the ground-truth
cell.
The second category is the strongest test of the proposed method because the recovery module
must create an instance rather than recover a discarded low-confidence prediction.
6.3 Baselines
The central comparison should keep the host detector fixed.
For whole-system context, report LGPMA, SEM, TableFormer, LORE, TableCenterNet, and
representative recent TSR systems where reproducible implementations and compatible evaluation
protocols are available. These comparisons should be presented separately from the same-detector
intervention table so that a change in backbone or decoding paradigm is not confused with the
effect of insertion.

6.4 Datasets
PubTables-1M contains approximately 947,642 tables and provides large-scale cell, row, and
column annotations, including complex tables with spanning cells [ 12]. SciTSR contains 15,000
scientific tables, with a designated complex subset (SciTSR-COMP) in the test set [ 28]. WTW
contains 14,581 table images and covers several types of natural visual deformation; its annotations
include quadrilateral cell geometry and logical row/column coordinates [8].
6.5 Metrics
The evaluation has two layers: standard TSR metrics and task-specific insertion metrics.
6.5.1 Standard TSR metrics
•GriTS: report topology, location, and content components where the dataset supports
them. GriTS was designed to compare table structures as grids and separates topology and
localization effects [18].
•TEDS: use for tree-structure similarity when an HTML-like representation is available [ 19].
•Cell localization: precision, recall, F1, AP 50, AP 75, and average recall where appropriate.
•SciTSR relation accuracy: report the standard cell adjacency relation precision, recall,
and F1 used for the dataset [28].
•WTW structure/localization: follow the official evaluation protocol and include logical
structure plus cell localization metrics; TEDS can be reported where the conversion to the
required tree format is reliable.
6.5.2 Candidate-recovery metrics
For the new intervention, define a prediction as a matched insertion when its box reaches a
chosen IoU threshold with an omitted ground-truth cell and its logical attachment is compatible.

The model should not be declared useful from a synthetic deletion experiment alone. Natural
omissions are the deciding evaluation.
8 Failure Analysis
A central part of the project is to record the failure modes created by insertion. At minimum,
each false positive should be assigned to one of the following categories:
1. false geometric gap;
2. over-segmentation of a spanning cell;
3. duplicate of an existing detector candidate;
4. incorrect box despite correct structural location;
5. incorrect logical row/column attachment;
6. unsupported insertion on an intact table.
For true recoveries, record whether the cell was filtered from a low-confidence candidate pool
or absent from the generous pre-filter pool. The second case should be reported as a separate
headline result.
9 Computational Scope and Feasibility
The initial system is intentionally modest. The first version does not require a large vision-
language model, OCR generation, reinforcement learning, or an exact optimizer. The host
detector and visual encoder can be kept frozen while the recovery module is trained. This makes
the first study feasible on a single consumer GPU with staged experiments.
A practical sequence is:

--- PAGE 12 ---
1. build the candidate-tracing and controlled-deletion pipeline;
2. implement geometric completion and lower-threshold baselines;
3. train an image-only insertion decoder;
4. add surviving-cell context;
5. evaluate natural omissions;
6. only then consider joint fine-tuning or a second host detector.
The first success criterion should be a controlled recovery result. The second is a natural-omission
result. End-to-end GriTS/TEDS gains come only after those two results are established.
10 Expected Research Contributions
The project will aim to deliver three concrete outputs.
1.A problem formulation: detection-conditioned cell insertion as a distinct stage between
initial cell prediction and final structural decoding.
2.A learned insertion architecture: a variable-cardinality decoder that uses image evidence
and surviving-cell context and can output “no insertion.”
3.An evaluation protocol: controlled candidate deletion and natural-omission analysis that
separates threshold rescue from genuine proposal generation.
The central empirical claim, if supported, will be:
At comparable insertion precision, a learned insertion module recovers more genuine
detector omissions than threshold relaxation and geometric gap completion, including
cells absent from a generous pre-filter candidate pool, while preserving valid spanning
structures.
This is the result that would justify a full TSR architecture paper. A small gain in a final table
metric without this evidence would not be sufficient.
11 Risks and Decision Criteria
A simple go/no-go rule is recommended:
Proceed to a larger architecture only if the full model beats geometric completion and
image-only recovery on natural omissions at a matched insertion-precision operating
point, and the gain includes cases absent from the generous pre-filter pool.

14 Conclusion
The literature does not leave a broad “missing-cell reconstruction” problem untouched. LGPMA
already combines structural vacancy reasoning with image-level information, historical-table work
generates missing cells from aligned detections, and recent TSR models increasingly combine
geometry and structure. The viable research question is narrower: whether a dedicated learned
insertion stage can expand an incomplete detector candidate set in a controlled way.
The initial architecture therefore remains deliberately small: a standard cell detector, a surviving-
cell context encoder, and a learned insertion decoder that attends to image features and can
output either a new cell or no insertion. The experimental design is more important than
architectural complexity. PubTables-1M will support the main ablations, SciTSR and SciTSR-
COMP will test dense structural layouts, and WTW will test deformed real-world tables. The
decisive evidence will be recovery of natural omissions that are absent from a generous candidate
pool, at a precision level that threshold relaxation and geometric completion cannot match.
